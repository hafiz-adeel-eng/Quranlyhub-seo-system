# کلاس ہیلپر (Windows)

یہ پروگرام Zoom کلاس کے دوران آپ کی اور طالبہ کی آواز سنتا ہے۔ جب طالبہ سوال پوچھتی ہے تو ایک چھوٹی کھڑکی میں مختصر انگریزی جواب دکھاتا ہے، جو آپ پڑھ کر بول سکتے ہیں۔ یہ Groq کی مفت سروس استعمال کرتا ہے۔

## ایک بار کا سیٹ اپ

1. **Python انسٹال کریں:** python.org سے Python ڈاؤن لوڈ کریں۔ انسٹال کرتے وقت نیچے **"Add python.exe to PATH"** پر ٹک ضرور لگائیں۔
2. **یہ فولڈر ڈاؤن لوڈ کریں:** GitHub پر برانچ `claude/quran-teaching-assistant-kduqbo` کھولیں، پھر **Code → Download ZIP** دبائیں۔ ZIP کو extract کریں اور `class-assistant` فولڈر کھولیں۔
3. **Groq key ڈالیں:** `start.bat` چلائیں۔ پہلی بار کھڑکی میں key مانگی جائے گی۔ Groq کی key کاپی کریں، کھڑکی میں **Paste** دبائیں، پھر **Save** دبائیں۔ key محفوظ ہو جائے گی اور اگلی بار دوبارہ نہیں مانگی جائے گی۔

## ہر کلاس میں

1. **ہیڈفون لگائیں۔** ورنہ طالبہ کی آواز آپ کے مائیک میں بھی چلی جائے گی اور سسٹم کو پتا نہیں چلے گا کہ کون بول رہا ہے۔
2. `start.bat` پر ڈبل کلک کریں۔ پہلی بار اسے کچھ پیکیج انسٹال کرنے میں ایک دو منٹ لگیں گے۔
3. ایک کالی کھڑکی کھلے گی جس پر **Listening...** لکھا ہوگا۔ اب Zoom کلاس شروع کریں۔
4. جب طالبہ سوال پوچھے گی تو سبز رنگ میں **SAY: ...** آئے گا۔ آپ وہ جملہ پڑھ کر بول دیں۔

- یہ کھڑکی عام طور پر Zoom کی اسکرین شیئرنگ میں نظر نہیں آتی (Windows 10 کے نئے ورژن یا Windows 11 پر)۔ پھر بھی پہلی بار ایک ٹیسٹ کال میں ضرور چیک کر لیں۔

## اگر مسئلہ ہو

- **شور پر بھی جواب آنے لگے:** `.env` میں `VOICE_LEVEL=800` لکھیں (نمبر بڑا کریں)۔
- **آواز پکڑی ہی نہ جائے:** `VOICE_LEVEL=300` لکھیں (نمبر چھوٹا کریں)۔
- **"rate limit" کا error آئے:** مفت پلان کی حد پوری ہو گئی ہے۔ `LISTEN_TO_TEACHER=no` لکھیں تاکہ صرف طالبہ کی آواز بھیجی جائے۔
- **طالبہ کی آواز نہ آئے:** Windows میں وہی اسپیکر یا ہیڈفون "Default" ہونا چاہیے جس پر Zoom کی آواز آ رہی ہے۔
- **جوابات کا انداز بدلنا ہو:** `prompt.txt` میں ہدایات بدلی جا سکتی ہیں۔

## ضروری باتیں

- `.env` فائل (آپ کی key) کسی کو نہ دیں اور نہ کہیں اپ لوڈ کریں۔
- طالبہ کو بتا دیں کہ کلاس میں مدد کے لیے لائیو ٹرانسکرپشن استعمال ہوتی ہے۔ اگر وہ کم عمر ہے تو والدین کو بھی بتائیں۔
- AI کبھی غلطی کر سکتا ہے۔ تلفظ اور دینی باتوں میں آخری فیصلہ ہمیشہ آپ کا ہے۔
